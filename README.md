# RAG 知识库问答系统

一个支持上传资料、检索相关内容并生成带引用回答的知识库问答系统。

## 当前进度

- 已完成：Python 虚拟环境、Git 仓库和 FastAPI 基础接口。
- 已完成：TXT 与 Markdown 文件读取，以及自动测试。
- 已完成：浏览器上传 TXT 与 Markdown 文件预览接口。
- 已完成：文本切分接口，默认每段 800 字符、重叠 100 字符。
- 已完成：云端向量 API 配置模板。
- 已完成：阿里云百炼兼容接口的向量调用模块。
- 已完成：基于 FAISS 的内存向量索引和相似度搜索。
- 下一步：把上传文档写入索引，并提供检索接口。

## 云端 API 配置

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写阿里云百炼的 API Key 和业务空间 ID。
3. `.env` 已被 Git 忽略，禁止提交或分享其中的 API Key。
